
# IBM Data Science Capstone Project – SpaceX

## Overview

This repository contains my final capstone project from the IBM Data Science Professional Certificate.

The project explores the use of data science techniques to investigate and predict the outcomes of SpaceX Falcon 9 rocket launches. The main objective is to collect, process, analyse and visualise launch data, and use machine learning to identify factors that may influence landing success.

The project covers several stages of a typical data science workflow, from gathering raw data to building predictive models.

## Project Workflow

### 1. Data Collection
- Retrieved launch data using the SpaceX API.
- Used web scraping to collect additional information.
- Combined data from different sources for further analysis.

### 2. Data Wrangling
- Cleaned and prepared the collected datasets.
- Handled missing and inconsistent values.
- Transformed raw data into a format suitable for analysis.

### 3. Exploratory Data Analysis
- Explored relationships between launch characteristics and landing outcomes.
- Used Python libraries for statistical analysis and visualisation.
- Investigated patterns and trends in the launch data.

### 4. Data Visualisation
- Created visualisations using Matplotlib, Seaborn and Plotly.
- Used Folium for geographical visualisation.
- Developed interactive dashboards with Plotly Dash.

### 5. Machine Learning
- Prepared the data for classification.
- Trained and evaluated machine learning models.
- Compared model performance to investigate which features were most useful for predicting landing success.

## Technologies Used

- **Python** – Main programming language
- **Pandas & NumPy** – Data manipulation and processing
- **SQL** – Database queries and data analysis
- **Requests & BeautifulSoup** – API access and web scraping
- **Matplotlib, Seaborn & Plotly** – Data visualisation
- **Folium** – Geographical visualisation
- **Scikit-learn** – Machine learning
- **Plotly Dash** – Interactive dashboards
- **Jupyter Notebook** – Development and experimentation

## What I Learned

This project gave me practical experience with the complete data science workflow, including collecting data from external sources, preparing and exploring datasets, performing statistical analysis, creating visualisations and developing predictive models.

It also provided experience combining different tools and techniques to turn raw data into useful information.

## Project Context

This is an educational project completed as part of the IBM Data Science Professional Certificate. The work demonstrates practical application of the methods and technologies covered throughout the course.
